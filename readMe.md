# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**. This project demonstrates core JavaScript concepts such as **DOM manipulation, event handling, arrays, loops, functions, and game logic**.

## ✨ Features

- 🎯 Two-player gameplay (O vs X)
- 🏆 Automatic winner detection
- 🔄 Reset Game functionality
- 🆕 New Game option
- 🚫 Prevents selecting an already occupied box
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎮 How to Play

1. Player **O** starts the game.
2. Players take turns placing **O** and **X** on the board.
3. The first player to complete a row, column, or diagonal wins.
4. Use the **Reset Game** or **New Game** button to play again.
